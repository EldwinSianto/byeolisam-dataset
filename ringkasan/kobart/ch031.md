# ch031 — kobart (5 kalimat dari 5 potongan dialog (174 baris))

- 양진수는 정철규에게 전학이나 다른 방법이 있지 않냐며 검정고시라고 말했다.
- 정철규가 얌전히 지냈더니 이젠 개나 소나 나를 ᄌ밥으로 보게 되었다.
- 정철규가 전화, 메신저를 다 쌩깠다고 하자 정철규는 우스운 거 아니냐고 했다.
- 지수원은 설효림에게 꿈의 내용이 이어져서 선물 같은 것을 주웠다.
- 설효림과 대화를 나눈 날은 기분이 좋다는지수원의 말에 설효림은 양진수가 계속 결석하니 맘이 복잡한 것 같다고 말했다.
